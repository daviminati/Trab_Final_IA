# Construção de um LLM From Scratch

Este repositório contém o desenvolvimento do **Projeto Integrador** do componente curricular **Inteligência Artificial e Sistemas Inteligentes**. O objetivo é implementar, de forma incremental e do zero (*from scratch*), um modelo de linguagem baseado na arquitetura Transformer (estilo GPT), utilizando PyTorch no Google Colab.

> **Referência Principal:** RASCHKA, Sebastian. *Build a Large Language Model (From Scratch)*. Manning Publications, 2024.
